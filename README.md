# מסמכי פלטפורמת התיירות הלאומית — גרסת קריאה מקושרת

אתר סטטי לצפייה בחמשת מסמכי הפרויקט, עם קישורים בין המסמכים ואפשרות להוסיף הערות על כל פסקה.

- **אבטחה:** כל דף שמור מוצפן (AES-256-CBC). המפתח נגזר בדפדפן מהסיסמה (PBKDF2-SHA256, 600,000 איטרציות) ונשמר רק בלשונית הפתוחה. בלי הסיסמה אין בקבצים טקסט קריא. הסיסמה אינה במאגר.
- **צפייה:** דרך GitHub Pages. הזינו את הסיסמה שקיבלתם; כפתור "נעילה" בתפריט מוחק את המפתח מהלשונית.
- **הערות:** משותפות לכל מי שנכנס עם הסיסמה. כל הערה אפשר לסמן "טופלה" (עם שם המסמן והתאריך) או לפתוח מחדש. ההערות מוצפנות בדפדפן לפני השליחה ונשמרות בפונקציה קטנה ב-Vercel (התיקייה `backend/`, פרויקט `tourism-docs-comments` בצוות rep, אחסון Vercel Blob פרטי), כך שהשרת רואה רק טקסט מוצפן. שינוי של קורא אחר מופיע אצל השאר תוך כדקה. בלי חיבור, ההערות נשמרות בדפדפן ונשלחות כשהחיבור חוזר. "ייצוא" ו"ייבוא" עדיין קיימים לגיבוי.
- **החלפת סיסמה** משנה גם את מפתח ההערות: לפני ההחלפה מייצאים את ההערות, אחרי הבנייה מעדכנים ב-Vercel את `COMMENTS_TOKEN_SHA256` לערך שהבנייה מדפיסה, פורסים מחדש (`cd backend && vercel deploy --prod`) ומייבאים את הקובץ.
- **אנליטיקה:** Microsoft Clarity (מזהה הפרויקט ב-`tools/config.json`).
- **בנייה מחדש** מקובצי המקור שבתיקייה `source/`: `python3 tools/build.py`. הסיסמה נקראת מהקובץ `.site-password` בשורש הפרויקט, ונוצרת אוטומטית אם חסרה.
